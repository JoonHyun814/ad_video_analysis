# Pikk 조명 태그 어휘

Pikk stills.pikk.co.kr 의 `visual` / `mood` 태그 중 조명 관련 태그 정리.  
기준: `pikk_tag_tree.json` 수집일 2026-09-15 · 전체 10,385 씬 기준 사용수.

---

## 분류기 레이블 ↔ Pikk 태그 매핑

우리 pixel 기반 분류기(`classifier.py`)의 4개 레이블과 Pikk 태그 군 연결.

| 분류기 레이블 | Pikk 주요 태그 군 | 분류기 감지 원리 |
|--------------|-----------------|----------------|
| `high_key`   | 하이키조명, 소프트하이키, 자연광하이키라이팅 | mean_brightness > 155 AND shadow_ratio < 0.12 |
| `low_key`    | 로우키조명, 시네마틱로우키, 드라마틱조명     | mean_brightness < 82 AND shadow_ratio > 0.38 |
| `backlight`  | 역광, 자연광역광, 실루엣, 골든아워역광      | bg_center_ratio > 1.45 AND center_brightness < 105 |
| `normal`     | 자연광, 부드러운조명, 따뜻한조명, 네온조명   | 위 조건 미충족 |

## 분류기 감지 범위 vs Pikk 태그 현황

| 그룹 | Pikk 총 사용수 (상위 태그 합산) | 현재 분류기 감지 여부 | 비고 |
|------|--------------------------------:|--------------------|------|
| 하이키 계열 | ~1,000 | ✅ `high_key` | mean_brightness + shadow_ratio |
| 로우키 계열 | ~1,700 | ✅ `low_key` | mean_brightness + shadow_ratio |
| 역광·실루엣 계열 | ~900 | ⚠️ `backlight` (부분 감지) | 실루엣 강도·골든아워 역광 등은 미감지 |
| 자연광 계열 | ~1,400 | ❌ `normal` 로 분류 | 밝기만으로 자연광 vs 인공광 구분 불가 |
| 드라마틱·시네마틱 | ~250 | ❌ `low_key` 로 흡수 또는 `normal` | 별도 감지 필요 |
| 네온·인공 조명 | ~300 | ❌ `normal` | 색조 분석(HSV) 필요 |
| 렌즈 플레어 | ~80 | ❌ 미감지 | 광학 효과 감지 별도 구현 필요 |
| 골든아워 | ~80 | ❌ `normal` 또는 `backlight` 일부 | 색온도 분석 필요 |

> **현재 분류기 감지 범위**: 전체 조명 씬의 약 **53%** (하이키 + 로우키 + 역광 일부)  
> **감지 안 되는 주요 군**: 자연광 (자연광 vs 인공광 구분), 골든아워, 네온, 렌즈플레어
