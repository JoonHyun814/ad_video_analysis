# Pikk 기법 도메인별 정리

도메인 간 기법 중복이 없도록 귀속을 결정한 레퍼런스.  
사용수: Pikk tag_tree 기준 canonical 태그 총합 (2026-09-15).  
검출: 현재 구현된 분류기의 감지 여부.

> **귀속 원칙**  
> - 탑뷰/버드아이뷰 → **앵글** (카메라 위치·방향 기법)  
> - 줌인/줌아웃 → **모션** (카메라 이동 기법)  
> - 모션블러 → **모션** (속도/이동으로 발생)  
> - 핸드헬드·드론 → **모션** (촬영 장비·이동 기법)  
> - 오버더숄더·1인칭 POV → **샷 사이즈** (피사체 배치·프레이밍)
