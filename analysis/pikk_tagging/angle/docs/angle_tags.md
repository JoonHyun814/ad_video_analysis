## 분류기 감지 범위 vs Pikk 태그 현황

> 분류기 미구현 상태 — 구현 후 업데이트 예정.

| 그룹 | Pikk 총 사용수 | 현재 분류기 감지 여부 | 비고 |
|------|:-------------:|--------------------|------|
| 탑뷰·버드아이 | 높음 | ❌ 미감지 | 수직 수렴 소실점 + 수평선 부재로 감지 예정 |
| 하이앵글 | 높음 | ❌ 미감지 | 수평선 위치 상단 편향 감지 |
| 로우앵글 | 높음 | ❌ 미감지 | 수평선 위치 하단 편향 감지 |
| 아이레벨 | 중간 | ❌ 미감지 | 수평선 중앙 + roll ≈ 0° |
