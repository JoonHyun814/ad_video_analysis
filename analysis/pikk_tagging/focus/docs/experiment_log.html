EXP 01 global_sharpness 단순 분류 vs center/bg ratio + rack_focus 감지 ▼
실험 설명

Before: global_sharpness < 40 → out_of_focus, 나머지 → normal.
After: center_bg_ratio 로 shallow_dof 감지, sharpness_delta 로 rack_focus 감지, 균일 선명도로 deep_focus 감지 추가.

가설: 중앙/배경 선명도 비율이 얕은 피사계심도(보케)를 효과적으로 감지하고, 시간축 선명도 변화가 랙 포커스를 구분한다.

Before (global_sharpness_only): global_sharpness < 40 → out_of_focus else → normal After (center_bg_ratio + rack_focus): global_sharpness < 40 → out_of_focus sharpness_delta > 700 → rack_focus center_bg_ratio > 2.5 → shallow_dof global_sharpness > 250 AND 0.7 < center_bg_ratio < 1.4 → deep_focus else → normal
