## 1. 얕은 피사계 심도 (Shallow DOF · 아웃포커싱)

| 태그명 | 사용수 | 타입 | 설명 |
|--------|-------:|------|------|
| 아웃포커싱 | 높음 | visual | 배경을 흐리게 처리해 피사체를 분리 |
| 얕은피사계심도 | 높음 | visual | 초점 범위가 좁아 배경·전경이 흐림 |
| 보케 | 높음 | visual | 배경의 흐린 빛 점들 (bokeh 효과) |
| 보케효과 | 중간 | visual | 보케를 의도적으로 활용한 연출 |
| 아웃포커스배경 | 중간 | visual | 배경만 아웃포커스, 피사체 선명 |
| 소프트배경 | 중간 | visual | 배경이 부드럽게 흐려진 구도 |
| 렌즈블러 | 중간 | visual | 렌즈 광학 특성으로 생긴 블러 |
| 크리미보케 | 낮음 | visual | 부드럽고 크리미한 보케 텍스처 |

## 2. 딥 포커스 (Deep Focus)

| 태그명 | 사용수 | 타입 | 설명 |
|--------|-------:|------|------|
| 딥포커스 | 중간 | visual | 전경부터 배경까지 전체 선명 |
| 팬포커스 | 낮음 | visual | 전체 영역 초점 유지 (= 딥 포커스) |
| 전체초점 | 낮음 | visual | 화면 전체가 고르게 선명 |
| 광각선명 | 낮음 | visual | 광각렌즈 특성으로 인한 넓은 피사계심도 |

## 3. 랙 포커스 (Rack Focus · 초점 이동)

| 태그명 | 사용수 | 타입 | 설명 |
|--------|-------:|------|------|
| 랙포커스 | 중간 | visual | 컷 내부에서 초점을 한 대상에서 다른 대상으로 이동 |
| 포커스이동 | 중간 | visual | 초점이 이동하는 연출 (랙포커스 총칭) |
| 포커스풀 | 낮음 | visual | 수동 포커스 조작으로 초점 이동 |
| 포커스샤프트 | 낮음 | visual | 급격한 초점 이동 효과 |
| 포커스트랜지션 | 낮음 | visual | 초점 이동을 장면 전환으로 활용 |

|--------|-------:|------|------|

## 분류기 감지 범위 vs Pikk 태그 현황

> 분류기 미구현 상태 — 구현 후 업데이트 예정.

| 그룹 | Pikk 총 사용수 | 현재 분류기 감지 여부 | 비고 |
|------|:-------------:|--------------------|------|
| 얕은DOF·아웃포커싱 | 높음 | ❌ 미감지 | Laplacian variance 중앙/외곽 비교로 구현 예정 |
| 딥 포커스 | 중간 | ❌ 미감지 | 전영역 선명도 균일 판단 |
| 랙 포커스 | 중간 | ❌ 미감지 | 시간축 선명도 변화 감지 |
| 소프트포커스·블러 | 중간 | ❌ 미감지 | 전영역 낮은 Laplacian |
| 모션블러 | 중간 | ❌ 미감지 | 방향성 있는 블러 패턴 분석 필요 |
