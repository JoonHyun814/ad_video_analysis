문제 & 해결
문제: mean_brightness 단독 분류는 역광(backlight) 을 감지할 수 없다. 역광 씬은 배경(하늘, 창문)이 밝고 주 피사체가 어두워 전체 평균 밝기는 중간값에 머무른다. 단순 임계값으로는 high_key / low_key 도 아닌 normal 로 분류된다.
해결: 프레임을 중앙 영역(40-60% 세로, 40-80% 가로)과 외곽 배경으로 분리. bg_center_ratio > 1.45 이고 배경 밝기 > 115, 중앙 밝기 < 105 이면 backlight 로 분류. 나머지는 기존 mean_brightness 기반 high/low key 규칙 유지.
분류 규칙
# classifier.py — classify_frame()
def classify_frame(stats):
    # 역광: 배경 밝고 중앙 어두움
    if (stats["bg_center_ratio"] > 1.45
            and stats["bg_brightness"] > 115.0
            and stats["center_brightness"] < 105.0):
        return "backlight"

    # 하이키: 전체 밝고 그림자 적음
    if stats["mean_brightness"] > 155.0 and stats["shadow_ratio"] < 0.12:
        return "high_key"

    # 로우키: 전체 어둡고 그림자 많음
    if stats["mean_brightness"] < 82.0 and stats["shadow_ratio"] > 0.38:
        return "low_key"

    return "normal"
