EXP 01 roll_angle 만 사용 vs roll + horizon 위치 추정 ▼
실험 설명

Before: |roll_angle_deg| > 15° → dutch_angle, 나머지 → eye_level.
After: roll 이후 horizon_y_ratio 로 high_angle / low_angle 구분, h_line_ratio 로 bird_eye 감지 추가.

가설: 수평선 위치 추정이 고각·저각 촬영 구분에 유효하며, 수평선이 지배적인 탑뷰 구도는 bird_eye 로 올바르게 분류된다.

Before (roll_only): |roll_angle_deg| > 15 → dutch_angle else → eye_level After (roll + horizon + bird_eye): |roll_angle_deg| > 15 → dutch_angle h_line_ratio > 0.65 AND v_line_ratio < 0.10 → bird_eye horizon_y_ratio < 0.35 → high_angle horizon_y_ratio > 0.65 → low_angle else → eye_level
