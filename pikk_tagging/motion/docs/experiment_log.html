문제 · 수정
0–420프레임 구간은 카메라가 완전 정지해 있지만 배경 피사체의 움직임으로 mean_mag 1–5px, pan ±2–4px/step, rotation ≈ ±0.010–0.013/step의 무작위 노이즈가 발생합니다. rolling sum이 9개 쌍을 모두 합산하면 노이즈가 누적되어 임계값을 넘으며 rotate_ccw·pan_right·pan_left·rotate_cw 오탐이 연속으로 발생했습니다.

pan/rotation 누적 합산의 문제: 방향이 무작위이면 기댓값은 0이지만 분산은 σ×√n 으로 증가해 합산값이 우연히 임계값을 초과합니다. zoom_score는 발산(divergence) 특성상 배경 모션 노이즈에 강인하므로 rolling sum fallback을 zoom_in/zoom_out 승격만으로 제한하였습니다.
# smooth.py — smooth_and_classify() 내부 - if acc_label not in ("static", "motion"): # pan/rotation도 승격 + if acc_label in ("zoom_in", "zoom_out"): # zoom만 승격 label = acc_label
