## 분류기 레이블 ↔ Pikk 태그 매핑

> 현재 구현된 분류기: `optical_flow` (Farneback + LK), `RAFT_step`

| 분류기 레이블 | Pikk 주요 태그 군 | 감지 원리 |
|--------------|-----------------|----------|
| `static` | 스태틱샷, 고정샷, 삼각대고정 | 전체 mean magnitude ≈ 0 |
| `pan` | 패닝, 수평패닝, 트래킹패닝 | mean(u) 또는 mean(v) 방향 편향 |
| `zoom_in` | 줌인, 디지털줌인, 푸시인 | optical flow divergence 양수 |
| `zoom_out` | 줌아웃, 풀백, 줌아웃연출 | optical flow divergence 음수 |
| `rotate` | 회전샷, 롤샷, 카메라롤 | curl 성분 주도 |

## 분류기 감지 범위 vs Pikk 태그 현황

| 그룹 | Pikk 총 사용수 | 현재 분류기 감지 여부 | 비고 |
|------|:-------------:|--------------------|------|
| 패닝·트래킹 | 높음 | ✅ `pan` | optical flow 방향 편향 감지 |
| 줌인·줌아웃 | 높음 | ✅ `zoom_in` / `zoom_out` | divergence 부호로 구분 |
| 정적 고정 | 높음 | ✅ `static` | mean magnitude 임계값 |
| 롤·회전 | 중간 | ✅ `rotate` | curl 성분 감지 |
| 핸드헬드 | 높음 | ❌ 미감지 | 고주파 흔들림 패턴 분석 필요 |
| 달리·스테디캠 | 중간 | ❌ `pan` 으로 흡수 | 물리적 이동 vs 렌즈 줌 구분 불가 |
| 드론 촬영 | 높음 | ❌ 미감지 | 조합 패턴 감지 필요 |
| 슬로우모션 | 높음 | ❌ 미감지 | 프레임레이트·시간 분석 필요 |
| 오빗·360도 | 중간 | ⚠️ `rotate` 일부 | 원형 경로 vs 단순 roll 미구분 |

> **현재 분류기 감지 범위**: 핵심 카메라 워크(static·pan·zoom·rotate) — 전체 모션 태그의 약 **40~50%**  
> **감지 안 되는 주요 군**: 핸드헬드(흔들림), 달리 vs 줌 구분, 드론, 슬로우모션
