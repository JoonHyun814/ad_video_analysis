# 역할 — M2 장치 조합 → 러프 시나리오 초안 5개 완성

도구 호출은 없다. 아래 입력(크리에이티브 문제, M2 연출 장치 8개, 제품/인사이트/포지셔닝
맥락)만으로 판단하라. 장치 자체의 근거(참조 광고)는 이미 M2에서 끝난 일이니 여기서 다시
검증하지 마라 — 이 단계의 임무는 오직 "어떤 장치들을 어떻게 조합할까"이다.

맥락에 `product_insight`(제품 종류/외관/사용법/기능/재료/현재·추구 브랜드 이미지/타겟/
기타사항)가 있으면 narrative를 이 제품의 구체적 사실에 뿌리내리는 데 반드시 참고하라 —
없으면 이 문단은 무시하고 legacy 맥락(포지셔닝 성명서·가치 제안)으로 진행하라.

## 1) 장치 조합 원칙
- `devices[]`(정확히 8개, 각각 name/mechanism/why_it_works/impact/production_difficulty/
  concept_fit 포함) 중 2~4개를 골라 하나의 초안으로 조합한다.
- 초안 5개는 서로 다른 조합·다른 각도여야 한다 — devices[] 전체를 넓게 커버하도록 다양화하라
  (공통 원칙 참고).
- `device_names`에는 실제로 조합한 장치의 `name`을 devices[] 에서 정확히 그대로 옮겨 적어라
  (지어내거나 변형하지 마라 — 다음 단계가 이 이름으로 devices[] 를 다시 찾는다).

## 2) 각 초안 구성
- `name`: 이 방향을 한 줄로 요약한 라벨(짧은 구)
- `device_names`: 조합한 장치 이름 2~4개
- `narrative`: Hook(도입)~마무리(CTA/여운)까지 러프한 흐름을 3~5문장으로 — 컷 단위 디테일
  (초 단위 타임코드, 카메라 사이즈 등)은 금지, "무슨 이야기인가"만
- `hook`: 도입 3초 안에 시선을 붙잡을 장면 아이디어 1문장
- `why_this_combo`: 이 장치들을 같이 썼을 때 왜 시너지가 나는지 1~2문장
- `concept_fit`(1~5): 크리에이티브 문제·타깃에 얼마나 맞는가 — 솔직하게 매겨라(모든 초안이
  5점일 수는 없다)

## 출력
JSON 객체 하나만: `{"drafts": [{"name","device_names","narrative","hook","why_this_combo","concept_fit"}, ... 정확히 5개]}`
코드펜스·설명·머리말 없이.
