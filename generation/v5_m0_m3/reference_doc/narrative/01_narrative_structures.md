이 외 더 많은 서사구조가 있지만, 국내 정서에 맞고 중복서사를 제외 선별한 서사구조입니다.
1) PAS
Problem → Agitation → Solution
문제 → 자극/증폭 → 해결
PAS는 광고에서 가장 많이 쓰이는 설득 구조 중 하나입니다.
소비자가 겪는 문제를 먼저 보여주고, 그 문제가 얼마나 불편하거나 심각한지 감정적으로 자극한 뒤,
제품이나 서비스가 해결책으로 등장합니다.
기본 흐름
광고 예시
“매일 아침 피부가 푸석푸석한가요?”
“화장도 잘 안 먹고, 거울 볼 때마다 스트레스라면?”
“이 앰플 하나로 아침 피부 컨디션을 바꿔보세요.”
영상에서의 특징
초반에 문제 상황이 빠르게 등장함
상황 단서(소품/배경/손동작), 자막, 내레이션으로 불편함을 강조함 (인물 얼굴 정면 클로즈업은 피한다)
중후반에 제품 등장
해결 후 긍정적인 변화나 CTA로 마무리

2) BAB
Before → After → Bridge
이전 상태 → 이후 상태 → 연결 수단
BAB는 사용 전과 사용 후의 차이를 보여주고, 그 차이를 만들어낸 수단으로 제품이나 서비스를 제시
하는 구조입니다.
기본 흐름
광고 예시
Before: “퇴근 후에도 집안일 때문에 쉬지 못하는 모습”
After: “로봇청소기 사용 후 여유롭게 쉬는 모습”
Bridge: “스마트 자동청소 기능이 있는 제품 소개”
Before
제품 사용 전의 상태. 불편함, 낮은 효
율, 아쉬운 상황
After
제품 사용 후의 좋아진 상태. 편리함,
만족, 변화
Bridge
Before에서 After로 가게 해주는 제
품/서비스
단계
설명
PerformanceByTBWA marketing tech.

영상에서의 특징
전후 대비가 뚜렷함
화면 톤이 바뀌는 경우가 많음
예: Before는 어둡고 답답하게, After는 밝고 여유롭게
자막으로 “사용 전 / 사용 후”, “3일 후”, “한 달 후” 등을 보여줄 수 있음
결과 변화가 핵심 메시지
PAS와의 차이
PAS는 문제를 파고들고, BAB는 변화 결과를 강조합니다.

4) hook-body-close
Hook → Body → Close
주의집중 → 본문 전달 → 마무리
hook-body-close는 숏폼 광고나 퍼포먼스 광고에서 가장 넓게 쓰이는 기본 구조입니다.
명확한 문제 해결 서사가 없더라도, 초반에 시선을 끌고 중간에 정보를 전달한 뒤 마지막에 브랜드나

다른 구조와의 관계

예를 들어 PAS 광고도 다음처럼 볼 수 있습니다.

6) non_narrative
비서사 구조
non_narrative는 명확한 이야기 흐름이 없는 광고입니다.
문제, 해결, 변화, 증언 같은 구조가 약하거나 없고, 브랜드 이미지, 감각적 장면, 음악, 시각적 리듬,
분위기로 메시지를 전달합니다.
기본 특징
원인과 결과가 뚜렷하지 않음
장면들이 스토리보다 분위기 중심으로 연결됨
제품의 구체적 기능 설명이 적음
브랜드 무드, 라이프스타일, 세계관, 감성 표현이 중요함
광고 예시
향수 광고
패션 브랜드 필름
자동차 브랜드 무드 필름
프리미엄 주류/호텔/럭셔리 브랜드 영상
추상적인 브랜드 캠페인
영상에서의 특징
음악과 영상미가 중요함
인물의 행동보다 이미지, 색감, 공간, 리듬이 중요함
장면 전환이 감각적임
대사나 설명이 거의 없을 수 있음
마지막에 로고나 슬로건만 등장하기도 함
판단 기준
영상이 “무슨 일이 일어났는가”보다 “어떤 느낌을 주는가”가 중요하다면 non_narrative에 가깝습니
다.
