1. 광고 영상의 3가지 핵심
① 내러티브 유형 (영상 전체의 설득 방식)
   "이 광고, 어떤 방식으로 당신을 설득하는가?"

   예: PAS — 문제 보여주고 → 불안 키우고 → 해결책 등장
       BAB — 쓰기 전/후 비교로 변화를 보여줌
       Testimonial — 실제 사용자 경험으로 신뢰를 만듦
       Hook-Body-Close — 숏폼의 기본기, 잡고 → 설명하고 → 닫는다
   
   → "영상 하나에는 하나의 설득 문법이 있다"

② 씬별 서사역할 (장면 하나하나의 기능)
   "이 장면은 영상 안에서 무슨 일을 하는가?"

   예: Hook — 첫 3초, 넘기지 못하게 잡는다
       Problem — "나도 저런 문제 있어" 공감
       Solution — 제품이 답으로 등장
       Proof — 믿게 만드는 수치/인증/후기
       CTA — "지금 구매하세요"
   
   → "씬은 각자 역할이 있다. 역할이 빠지면 광고가 무너진다"

③ 키비주얼 (광고를 대표하는 핵심 장면)
   "이 광고에서 딱 한 장면을 고른다면?"

   광고기획자 관점: 메시지가 가장 압축된 장면
   아트디렉터 관점: 시각적으로 가장 강한 장면
   → "이 둘을 구별하고 판단할 수 있어야 한다"

2. 광고 영상 제작 과정
①우리가 필요한 것
"15초 또는 30초 안에 시청자를 구매로 이끄는 영상"

②차이를 만드는 것
→ 어떤 서사구조가 어떤 업종에서 전환율이 높은가
→ Hook의 첫 3초가 어떤 패턴일 때 이탈률이 낮은가
→ 키비주얼이 어디 배치됐을 때 ROAS가 올라가는가

③기획 순서: 
1)업종/목표 분석
2)서사구조 자동 선택 (PAS? BAB? Hook-Body-Close?)
3)씬별 역할 자동 배분 (Hook 1씬 / Problem 1씬 / Solution 2씬 / CTA 1씬...)
4)키비주얼 선정
5)검증
"이 씬, 진짜 Hook 역할 하고 있어?" → 서사역할 자동 검증
"키비주얼이 메시지를 담고 있어?" → 품질 자동 평가
광고기획자 관점 키비주얼과 아트디렉터 관점 키비주얼을 각각 자동 선별
