| 기법 | 핵심 개념 | 작동 방식 | 대표 사례 |
| :--- | :--- | :--- | :--- |
| **1. 경험 은유 (Experience Metaphor)** | 제품 경험의 치환 | 기기나 기능 자체보다, 제품 사용 시 느끼는 감각적 경험이나 순간을 비유적으로 표현 | 다트비트 (기기 대신 집에서 세계와 연결되는 순간 묘사) |
| **2. 리프레이밍 (Reframing)** | 관점의 재정의 | 제품의 기능은 두고, 제품이 속한 카테고리나 맥락의 의미(Frame)를 새롭게 규정 | 에이스침대 (가구 → 과학), 켈로그 (간식 → 아침 식사 대용) |
| **3. 디스럽션 (Disruption)** | 관습의 파괴 | 해당 시장에서 당연하게 여기는 통념을 찾아내 깨뜨리고 새로운 브랜드 비전 제시 | 애플 'Think Different' (성능/스펙 나열 관습 파괴) |
| **4. 환유 및 제유 (Metonymy)** | 대표 속성의 인접화 | 브랜드 전체를 보여주는 대신, 가장 상징적인 일부 특성이나 '결과'를 부각해 가치 대변 | 볼보 (차의 외형 대신 '안전벨트'나 '문소리'로 안전 각인) |
| **5. JTBD (Jobs-To-Be-Done)** | 과업 수행 프레임 | 소비자가 특정 문제를 해결하기 위해 제품을 '고용'한다는 관점에서 본질적 과업에 집중 | 슬랙 (단순 협업 툴 → 쓸데없는 이메일과 미팅 제거) |
| **6. PAS 모델 (Problem-Agitate-Solve)**| 문제 제기 및 자극 | 소비자의 불편함(Problem)을 짚고, 이를 극대화(Agitate)한 후 제품을 해결책(Solve)으로 제시 | 스니커즈 ("너 출출할 때 너 아니잖아" - 상황 극화 및 해결) |
| **7. 의인화 및 페르소나 (Anthropomorphism)**| 인격과 캐릭터 부여 | 무생물이나 추상적 서비스에 인간적인 성격, 행동, 대사를 부여하여 감정적 몰입 유도 | M&M's (초콜릿 알맹이 각각에 뚜렷한 성격과 인격 부여) |
